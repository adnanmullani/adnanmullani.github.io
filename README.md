# Adnan Mullani — Cinematic DevOps Portfolio

A premium, animation-first DevOps portfolio with a dark blue/cyan visual system. It combines a recruiter-friendly information architecture with cinematic interactions: boot sequence, particle field, animated deployment pipeline, infrastructure map, project deck, security scene, cloud stack, and career timeline.

## Run
Open `index.html` in a modern browser, or serve the folder locally with any static server.

## Files
- `index.html` — portfolio content and structure
- `style.css` — visual system, responsive layout and animations
- `script.js` — particles, cursor, reveal and interaction logic
- `assets/adnan.png` — profile image
- `assets/Adnan_Mullani_DevOps_Resume.pdf` — resume

## Notes
- The portfolio uses the user's supplied resume as the source for experience and project claims.
- GCP is presented as cloud-platform familiarity rather than invented production experience.
- The supplied reference portfolio was used only as a design/interaction benchmark; its source/assets are not copied.
